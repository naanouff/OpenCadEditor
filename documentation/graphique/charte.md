# Charte openCAD Editor

Source : [planche-identite.svg](planche-identite.svg) (planche vectorielle openCAD, Editor & TEAM). Aperçu raster : [planche-identite-opencad-editor.png](planche-identite-opencad-editor.png).

Les symboles du kit sont **ceux de la planche** (`icon-opencad-std`, `icon-editor-std`, `icon-team-std`, versions light et mini). Pas de redessin.

## Thèmes applicatifs

- **Dark** (défaut) : navy + cyan marque ; orange réservé au **mode Sketch**.
- **Light** : papier froid ; cyan actions ; orange Sketch.

Sémantique CAD : add vert, cut rouge, preview = cyan (hors Sketch).

## Composants (planche)

- Champs : coins arrondis, icône + placeholder ; bordure cyan **ou** orange Sketch.
- Boutons primaires : cyan (LOGIN, DASHBOARD, SETTINGS, CONTACT).
- Bouton **SKETCH** : orange, même forme.
