# Sprint 02 — veille des interfaces

Produit la note décrite dans [plan-interfaces.md](../veille/plan-interfaces.md). La note est [interfaces.md](../veille/interfaces.md). La maquette de layout n’est pas reprise dans ce sprint.

## But

Avoir, pour chaque modeleur 3D du benchmark, une capture publique et le repérage du ruban, de l’historique, du viewport et du panneau de fonction.

## Périmètre

1. Enregistrer les images dans `documentation/veille/interfaces/`, une par logiciel retenu, nom stable.
2. Rédiger `documentation/veille/interfaces.md` : image, URL, quatre repères, une observation. AutoCAD en contraste. OpenSCAD et CadQuery sans ruban. Les trois PLM cités sans capture de modeleur.
3. Lier la note depuis [documentation/README.md](../README.md).

Hors sprint : modifier [maquette/index.html](../maquette/index.html), dessiner un nouveau layout, coder l’éditeur.

## Terminé quand

- Chaque modeleur 3D de la liste a soit un fichier image crédité, soit une URL et l’explication de l’absence de fichier.
- La note ne décrit pas une capture qui n’est pas dans le dossier.
- Le journal dit que cette veille précède toute reprise du layout.
